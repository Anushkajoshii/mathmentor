# Common Mistakes & Pitfalls in JEE Math

## Algebra Mistakes
- Forgetting ± when taking square roots: √(x²) = |x|, not x
- Dividing both sides by a variable without checking if it could be zero
- Incorrect sign when expanding (a-b)²: it's a² - 2ab + b², NOT a² - b²
- Forgetting that log is only defined for positive numbers
- Confusing AP sum formula: Sₙ = n/2(first + last), not n(first + last)

## Calculus Mistakes
- Forgetting the chain rule: d/dx[sin(2x)] = 2cos(2x), not cos(2x)
- Not checking if L'Hôpital's rule applies (must be 0/0 or ∞/∞ form)
- Missing the constant of integration in indefinite integrals
- Confusing d/dx[eˣ] = eˣ with d/dx[aˣ] = aˣ·ln(a)
- Not verifying critical points are max/min (use second derivative test)

## Probability Mistakes
- Adding probabilities of non-mutually-exclusive events without subtracting intersection
- Confusing P(A|B) with P(B|A) - they are NOT the same
- Forgetting "with replacement" vs "without replacement" changes the calculation
- Using permutations when combinations are needed (order matters vs doesn't)
- Not considering all possible cases in conditional probability

## Linear Algebra Mistakes
- Assuming matrix multiplication is commutative (AB ≠ BA generally)
- Computing determinant incorrectly - watch the signs in cofactor expansion
- Forgetting det(kA) = kⁿ·det(A), not k·det(A)
- Not checking if inverse exists before trying to compute it (det must be ≠ 0)

## General Problem-Solving Mistakes
- Not reading the question carefully - missing constraints
- Not checking if the answer makes sense (negative probability? distance?)
- Skipping unit/domain checks
- Not considering edge cases (x = 0, empty set, etc.)
