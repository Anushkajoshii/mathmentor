# Algebra - Key Formulas & Identities (JEE Level)

## Quadratic Equations
- Standard form: ax² + bx + c = 0
- Quadratic formula: x = (-b ± √(b² - 4ac)) / 2a
- Discriminant D = b² - 4ac
  - D > 0: Two distinct real roots
  - D = 0: Two equal real roots (repeated root)
  - D < 0: No real roots (complex roots)
- Sum of roots: α + β = -b/a
- Product of roots: αβ = c/a

## Factoring Identities
- a² - b² = (a+b)(a-b)
- a³ - b³ = (a-b)(a² + ab + b²)
- a³ + b³ = (a+b)(a² - ab + b²)
- (a+b)² = a² + 2ab + b²
- (a-b)² = a² - 2ab + b²
- (a+b)³ = a³ + 3a²b + 3ab² + b³

## Binomial Theorem
- (x+y)ⁿ = Σ C(n,k) * x^(n-k) * y^k for k=0 to n
- C(n,k) = n! / (k!(n-k)!)
- General term: T(r+1) = C(n,r) * x^(n-r) * y^r

## Arithmetic Progression (AP)
- nth term: aₙ = a₁ + (n-1)d
- Sum of n terms: Sₙ = n/2 * (2a₁ + (n-1)d) = n/2 * (a₁ + aₙ)

## Geometric Progression (GP)
- nth term: aₙ = a₁ * r^(n-1)
- Sum of n terms: Sₙ = a₁(rⁿ - 1)/(r - 1) when r ≠ 1
- Sum to infinity (|r| < 1): S∞ = a₁/(1-r)

## Logarithms
- log(ab) = log(a) + log(b)
- log(a/b) = log(a) - log(b)
- log(aⁿ) = n·log(a)
- Change of base: logₐ(b) = log(b)/log(a)

## Inequalities
- AM ≥ GM ≥ HM for positive numbers
- AM = (a+b)/2, GM = √(ab), HM = 2ab/(a+b)
- Cauchy-Schwarz: (Σaᵢbᵢ)² ≤ (Σaᵢ²)(Σbᵢ²)
