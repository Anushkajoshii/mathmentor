# Domain & Constraint Rules in Mathematics

## Square Root
√x requires x ≥ 0 for real numbers.

## Logarithms
log(x) requires x > 0.

## Denominators
Denominator cannot equal zero.

Example:
1/(x−2) → x ≠ 2

## Probability Constraints
0 ≤ P(A) ≤ 1

## Trigonometric Constraints
tan(x) undefined when cos(x) = 0

## Even Roots
√(x²) = |x| not x.
