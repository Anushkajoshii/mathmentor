# Solution Templates for Math Problems

## Quadratic Equation Strategy
1. Write the equation in standard form ax² + bx + c = 0
2. Compute the discriminant D = b² - 4ac
3. If D > 0 → two real roots
4. If D = 0 → one repeated root
5. If D < 0 → complex roots
6. Apply quadratic formula:
   x = (-b ± √(b² - 4ac)) / 2a
7. Verify solution by substituting back.

## Probability Problem Strategy

1. Identify the sample space
2. Identify favorable outcomes
3. Check if events are independent
4. Use formulas:
   - P(A∪B) = P(A) + P(B) − P(A∩B)
   - P(A|B) = P(A∩B) / P(B)
5. Ensure final probability is between 0 and 1.

## Optimization Strategy (Calculus)

1. Define objective function f(x)
2. Compute derivative f'(x)
3. Solve f'(x) = 0
4. Check second derivative
5. Confirm maxima or minima
6. State optimal value
